# Rota Inteligente: Otimização de Entregas com Algoritmos de IA

## Sobre o projeto
O projeto demonstra como algoritmos de Inteligência Artificial podem ajudar a otimizar as rotas de entrega da empresa fictícia Sabor Express.

## Problema
Rotas mal planejadas podem aumentar as distâncias percorridas, o tempo de entrega e os custos operacionais.

## Objetivos
- Representar pontos de entrega por meio de um grafo.
- Encontrar rotas usando o algoritmo A*.
- Agrupar pontos utilizando o K-Means.
- Analisar os resultados obtidos.

## Tecnologias utilizadas
- Python
- Google Colab
- Pandas
- NetworkX
- Matplotlib
- Scikit-learn

## Metodologia
Os pontos representam locais de entrega e as ligações representam ruas com pesos fictícios. O algoritmo A* calcula caminhos entre os pontos, enquanto o K-Means agrupa locais para auxiliar na organização das entregas.

## Resultados
Foram gerados resultados de rotas, agrupamentos e gráficos para visualizar os dados. Os dados utilizados são fictícios e servem para demonstrar os algoritmos.

## Limitações e melhorias
O projeto não utiliza dados reais de trânsito. Futuramente, poderá ser aprimorado com mapas reais, informações de trânsito e dados reais de entregas.

## Conclusão
O uso dos algoritmos A* e K-Means demonstra como a Inteligência Artificial pode auxiliar no planejamento de rotas e na organização de entregas.
